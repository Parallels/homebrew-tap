# Parallels Homebrew tap

Homebrew distribution for [pdfm-mcp](https://github.com/Parallels/pdfm-mcp), an MCP server for Parallels Desktop virtual machines on macOS.

## Availability

The tap is ready for publication. The `pdfm-mcp` cask will be added automatically by the first stable product release with Homebrew publication enabled. Canary and beta releases do not update this tap.

## Install

Once the stable cask is published:

```sh
brew tap Parallels/tap
brew install --cask Parallels/tap/pdfm-mcp
pdfm-mcp --version
```

Parallels Desktop is required to use the VM tools. The release archive contains a universal binary for Apple Silicon and Intel Macs.

```sh
brew upgrade --cask pdfm-mcp
brew uninstall --cask pdfm-mcp
```

## Connect an MCP client

GUI clients need the absolute binary path. For Claude Code:

```sh
claude mcp add pdfm-mcp -- "$(brew --prefix)/bin/pdfm-mcp"
```

For Claude Desktop, add this to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "pdfm-mcp": {
      "command": "/opt/homebrew/bin/pdfm-mcp"
    }
  }
}
```

Use `/usr/local/bin/pdfm-mcp` on Intel Macs. Restart the client after editing. Remove its MCP entry when uninstalling.

## Maintainers

`Casks/pdfm-mcp.rb` is generated by GoReleaser in the product repository. Its release workflow normalizes and audits the cask before pushing it here. Do not publish a cask with a placeholder checksum or an unpublished release URL.

In `Parallels/pdfm-mcp`:

1. Add `HOMEBREW_TAP_TOKEN` to the protected `release` environment secrets. Use a fine-grained token scoped to `Parallels/homebrew-tap`, with Contents read/write. Use an approved service account or GitHub App; do not commit credentials.
2. Set the repository Actions variable `PUBLISH_HOMEBREW` to `true` when ready to publish.
3. Run the production release workflow. It publishes the stable archive and then updates this tap.

The tap CI checks cask style and performs a strict online audit on pushes, pull requests, and weekly. Until the first cask is published it reports that the tap is awaiting a stable release.
